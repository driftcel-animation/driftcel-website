# Driftcel — Real Website Build

This is a real HTML/CSS/JS implementation inspired by the supplied Driftcel reference.

Important: the reference image is NOT used as the website background. The hero world, typography, navigation, buttons, project cards, and responsive layout are built as web elements with HTML/CSS.

## Files
- index.html — page structure and content
- style.css — visual design and responsive layout

## Run locally
Open `index.html` in a browser.

## Publish free
Upload `index.html` and `style.css` to a GitHub repository, enable GitHub Pages, then connect `driftcel.com` through GoDaddy DNS.

## Before launch
Replace placeholder project descriptions and social links with your real content. If you don't have `hello@driftcel.com` yet, change the email address in index.html.
